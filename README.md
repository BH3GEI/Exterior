# Exterior

外装代脑。你的思考，放在你的外面。

## 原则

- **能不写就不写。**
- 它不是别人，是你的一部分。一旦它开始像个助手，就做偏了。

## 形状

- 一个节点就是一个念头。没有 session。
- 节点之间只有一种关系：从哪个念头长出来。一个念头可以有多个来路（合并），所以是 DAG，不是树。
- 一开始只有一个输入框；想法分叉时，自然长成一张网。手机竖着排，电脑横着排。
- 上下文就是来路：从当前节点回溯到所有根，共同祖先只算一次。
- 打开时：最近的几个末端节点，加一个空输入框。

## 后端只做三件事

1. 调 LLM（换模型 = 换 URL）
2. 执行 bash（唯一的工具）
3. 写 JSONL

## 不做

- 沙箱、确认 —— 思考不该被打断，整台电脑都是它的大脑
- 文件管理
- 记忆系统、索引、自动检索 —— 联想是你的事；它要翻旧账，自己 grep
- 自我保护 —— 死了就重启，节点都在 JSONL 里

解析和渲染（折叠、点击）放在前端。
